# Data Access

## Summary

| Material | Status |
|---|---|
| Aggregate result tables | Public in this repository |
| Report, figures, provenance and claim statements | Public in this repository |
| Item-level scored outputs and per-call judge ledgers | Not yet exported |
| Validation benchmark prompt and reference text | Controlled access, pending rights review |
| Primary-test holdout | Sealed. Not released, not requestable |
| Model weights and adapters | Not released |

## Validation benchmark

The Technical Report No. 2 validation benchmark is held under controlled access while a
per-item rights review is completed. That review assigns every item one of: original and
releasable; derived from a source with compatible redistribution rights; releasable with
citation or limited fields only; controlled access; or excluded from any public set.

Until that review is complete we do not publish prompt or reference text, and we do not
make blanket statements about the corpus in place of per-item decisions.

To enquire about access, contact the corresponding author listed in the report.

## Primary-test holdout

The primary-test holdout is not covered by this policy and is not available under any
access tier. It remains sealed. It is a one-time resource reserved for a prospectively
registered successor candidate whose outcome could change a decision, and requests for it
will be declined.

## Item-level evidence

Sanitized item-level scored outputs, exclusion records, analysis locks, artifact bindings,
and judge ledgers are not included in the current release. When exported, they will exclude
private provider responses, credentials, keys, holdout material, and session transcripts.

No date is committed for that export.
