# Vinci Technical Report No. 3: Runtime Pass Is Not Correctness

The configured P-BREVE-01-R2 SFT+DPO recipe did not establish a training-attributable reasoning-efficiency improvement on Qwen3.8-27B. The stronger screened effect could not be attributed cleanly to trained weights after a serving-effort control. More consequentially, the original executable-code bank accepted 24/24 shortcut programs, and its replacement still failed independent qualification.
