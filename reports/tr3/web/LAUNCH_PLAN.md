# Publication Sequence

1. Merge or permanently preserve the evidence cutoff commit.
2. Add the report package to `vinci-technical-reports/reports/tr3/`.
3. Publish the canonical research page and verify every download link.
4. Create the GitHub release and attach the PDF and full package ZIP.
5. Deposit the package in Zenodo; add the assigned DOI to GitHub and the research page.
6. Submit the arXiv source, obtain endorsement if requested, and inspect the generated preview.
7. Add the arXiv identifier to GitHub, Zenodo, and the research page.
8. Publish the founder blog, newsroom post, newsletter, and social thread.
9. Monitor for semantic collisions in third-party summaries: the sign convention, the two 10.9% values, and the two 21/40 values are the highest-risk compressions.
